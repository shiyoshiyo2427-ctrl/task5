# Task 5 – Simple Calculator

## Start here
1. Keep your official EdBytes starter ZIP and extracted folder untouched.
2. This is a separate sample implementation to help you understand the required calculator.
3. Open `index.html` in a modern browser to run it.
4. Compare this sample with the official starter files and transfer the required logic into the official starter if its filenames or layout differ.

## Required features included
- Reads two numeric inputs.
- Implements add, subtract, multiply and divide as separate functions.
- Displays a useful message for blank/non-numeric input.
- Prevents division by zero and displays an error message.

## Files
- `index.html` – calculator structure and two number inputs
- `style.css` – responsive styling
- `app.js` – four functions, validation and button events
- `TEST-NOTES.md` – five test examples
- `PASS-CHECKLIST.md` – required checks

No installation is needed for this sample.
